The API v1 base URL is `https://api.neural4d.com/openapi/v1`. This guide uses text-to-3D to show the core workflow.

## 1. Set your API key

Use an account with an active paid subscription to get your key from the [API key page](https://www.neural4d.com/account?api).

## 2. Create a 3D generation task

Submit a prompt to generate a textured 3D model. Send your key in the `Authorization: Bearer` header with every request.

```bash cURL
curl --request POST \
  --url 'https://api.neural4d.com/openapi/v1/3dmodels/generations' \
  --header "Authorization: Bearer ${YOUR_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "dreamtech/neural4d-2.5",
    "prompt": "A ceramic teapot on a white studio background",
    "with_texture": true
  }'
```

The API returns `202 Accepted`. Save the task `id` for the next step.

```json 202 Accepted
{
  "id": "normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d",
  "status": "queued",
  "created_at": 1784044800,
  "mode": "text_to_3d",
  "model": "dreamtech/neural4d-2.5",
  "data": [
    {
      "uuid": "72e30159-a242-4491-a67c-2ad0cfc9efb6",
      "status": "queued",
      "created_at": 1784044800
    }
  ],
  "usage": {
    "credits": 30
  }
}
```

## 3. Retrieve and download the result

Replace the sample `id` with the value returned when you created the task, then query every few seconds. `queued` and `processing` mean the task is still running. Stop at `succeeded` or `failed`; check `error` if it failed.

```bash cURL
curl --request GET \
  --url 'https://api.neural4d.com/openapi/v1/tasks/task-info?id=normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d' \
  --header "Authorization: Bearer ${YOUR_API_KEY}"
```

```json 200 OK
{
  "id": "normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d",
  "status": "succeeded",
  "model": "dreamtech/neural4d-2.5",
  "created_at": 1784044800,
  "updated_at": 1784044842,
  "mode": "text_to_3d",
  "output": {
    "models": [
      {
        "uuid": "72e30159-a242-4491-a67c-2ad0cfc9efb6",
        "url": "https://cdn.neural4d.com/results/model.glb",
        "format": "glb",
        "thumbnail_url": "https://cdn.neural4d.com/results/t1.png",
        "mesh_quality": "standard",
        "pose": "auto",
        "target_polycount": 500000,
        "topology": "triangle",
        "with_texture": true,
        "with_pbr": false,
        "image_enhancement": false,
        "mode": "text_to_3d",
        "status": "succeeded",
        "created_at": 1784044800,
        "updated_at": 1784044842
      }
    ]
  },
  "usage": {
    "credits": 30
  }
}
```

After the task succeeds, download the model from `output.models[0].url` and view its preview image at `output.models[0].thumbnail_url`. Both are temporary signed URLs. Retrieve the task again to get fresh URLs after they expire.
