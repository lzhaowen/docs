API v1 uses the `https://api.neural4d.com/openapi/v1` base path. Every request requires an API key provided by Neural4D.

## Request flow

<Steps>
  <Step title="List available models">
    Query the model catalog and use the returned capabilities to construct requests.

    <CodeGroup>
      ```bash cURL
      curl 'https://api.neural4d.com/openapi/v1/models' \
        --header 'Authorization: Bearer ${YOUR_API_KEY}'
      ```

      ```python Python
      import os
      import requests

      response = requests.get(
          "https://api.neural4d.com/openapi/v1/models",
          headers={"Authorization": f"Bearer {os.environ['YOUR_API_KEY']}"},
      )
      print(response.json())
      ```

      ```javascript Node.js
      const response = await fetch("https://api.neural4d.com/openapi/v1/models", {
        headers: {
          Authorization: `Bearer ${process.env.YOUR_API_KEY}`,
        },
      });

      console.log(await response.json());
      ```

      ```go Go
      package main

      import (
          "fmt"
          "io"
          "net/http"
          "os"
      )

      func main() {
          request, _ := http.NewRequest("GET", "https://api.neural4d.com/openapi/v1/models", nil)
          request.Header.Set("Authorization", "Bearer "+os.Getenv("YOUR_API_KEY"))

          response, _ := http.DefaultClient.Do(request)
          defer response.Body.Close()
          body, _ := io.ReadAll(response.Body)
          fmt.Println(string(body))
      }
      ```
    </CodeGroup>
  </Step>

  <Step title="Submit a generation task">
    Creation endpoints return `202 Accepted` and one task object for each requested output.

    <CodeGroup>
      ```bash cURL
      curl 'https://api.neural4d.com/openapi/v1/images/generations' \
        --header 'Authorization: Bearer ${YOUR_API_KEY}' \
        --header 'Content-Type: application/json' \
        --data '{
          "model": "openai/gpt-image-2",
          "prompt": "A ceramic teapot on a white studio background",
          "mode": "text-to-image",
          "n": 1,
          "resolution": "1K",
          "aspect_ratio": "1:1"
        }'
      ```

      ```python Python
      import os
      import requests

      response = requests.post(
          "https://api.neural4d.com/openapi/v1/images/generations",
          headers={"Authorization": f"Bearer {os.environ['YOUR_API_KEY']}"},
          json={
              "model": "openai/gpt-image-2",
              "prompt": "A ceramic teapot on a white studio background",
              "mode": "text-to-image",
              "n": 1,
              "resolution": "1K",
              "aspect_ratio": "1:1",
          },
      )
      print(response.json())
      ```

      ```javascript Node.js
      const response = await fetch("https://api.neural4d.com/openapi/v1/images/generations", {
        method: "POST",
        headers: {
          Authorization: `Bearer ${process.env.YOUR_API_KEY}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model: "openai/gpt-image-2",
          prompt: "A ceramic teapot on a white studio background",
          mode: "text-to-image",
          n: 1,
          resolution: "1K",
          aspect_ratio: "1:1",
        }),
      });

      console.log(await response.json());
      ```

      ```go Go
      package main

      import (
          "bytes"
          "fmt"
          "io"
          "net/http"
          "os"
      )

      func main() {
          body := []byte(`{"model":"openai/gpt-image-2","prompt":"A ceramic teapot on a white studio background","mode":"text-to-image","n":1,"resolution":"1K","aspect_ratio":"1:1"}`)
          request, _ := http.NewRequest("POST", "https://api.neural4d.com/openapi/v1/images/generations", bytes.NewReader(body))
          request.Header.Set("Authorization", "Bearer "+os.Getenv("YOUR_API_KEY"))
          request.Header.Set("Content-Type", "application/json")

          response, _ := http.DefaultClient.Do(request)
          defer response.Body.Close()
          result, _ := io.ReadAll(response.Body)
          fmt.Println(string(result))
      }
      ```
    </CodeGroup>
  </Step>

  <Step title="Poll the task">
    Store the returned task `id`, then call `GET /openapi/v1/tasks/{id}` until its status is `succeeded` or `failed`.
  </Step>

  <Step title="Retrieve result files">
    Call `GET /openapi/v1/files/{id}` after the task succeeds. Returned URLs are signed and temporary; keep the `id` as the permanent identifier.
  </Step>
</Steps>

See [Common headers](/en/common-headers) for authentication, request tracing, and rate-limit headers.
