Use `https://api.neural4d.com/openapi/v1` as the base path and send your API key as `Authorization: Bearer ${YOUR_API_KEY}`.

<Note>
  Video generation requests use JSON. Put first-frame and last-frame images in `frame_images`, and put typed image, video, or audio references in `input_references`. Upload every input first and use the returned `file_id`.
</Note>

## Request flow

1. Upload each reusable input with `POST /openapi/v1/files` and store the returned `file_id`.
2. Submit `POST /openapi/v1/videos/generations` and store the returned task `id`.
3. Poll `GET /openapi/v1/tasks/task-info?id={id}` until the task reaches a terminal status.
4. Read the child `uuid`, `aspect_ratio`, `mode`, and generated video URL from `output.videos`.
