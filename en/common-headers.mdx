title: "Common headers"
description: "Authentication and request tracing headers shared by API v1 endpoints."
---

## Authorization

Send your API key with the Bearer scheme on every request.

```http
Authorization: Bearer ${YOUR_API_KEY}
```

## X-Request-Id

`X-Request-Id` is optional. Send a unique value to correlate client logs with Neural4D logs. When omitted, the service generates a value and returns it in the response.

```http
X-Request-Id: req_01J2R6Y7F6Q8K9P0M1N2B3V4CX
```

| Header | Direction | Description |
| --- | --- | --- |
| `Authorization` | Request | Required API key using the Bearer scheme. |
| `X-Request-Id` | Request and response | Optional request trace ID; generated by the service when omitted. |
