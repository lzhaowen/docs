## Authorizations

<ParamField header="Authorization" type="string" required default={'Bearer ${YOUR_API_KEY}'}>
  Use the bearer token provided through the Neural4D website.
</ParamField>

## Body <span className="api-content-type">multipart/form-data</span>

<ParamField body="images" type="string&lt;binary&gt;[]" required>
  Input image files used to generate chibi-style models.

Allowed array length: `1 - unbounded` elements.
</ParamField>
<ParamField body="styleType" type="string" required>
  Configured prompt tag used by the cute-model workflow.

Example: `"Pixel-Style"`.
</ParamField>

<RequestExample>
```bash cURL
curl --request POST \
  --url https://alb.neural4d.com:3000/api/createCuteModelsFromImages \
  --header 'Authorization: Bearer <token>' \
  --form 'images=@/path/to/file' \
  --form 'styleType=Pixel-Style'
```
