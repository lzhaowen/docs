## Authorizations

<ParamField header="Authorization" type="string" required default={'Bearer ${YOUR_API_KEY}'}>
  Neural4D API key using the Bearer scheme.
</ParamField>

## Body <span className="api-content-type">multipart/form-data</span>

<ParamField body="file" type="string&lt;binary&gt;" required>
  File to upload. Supported image formats: JPG, JPEG, PNG, GIF, WEBP, BMP, HEIC, and HEIF. Supported video formats: MP4, MOV, WEBM, M4V, OGG, and OGV. Supported audio formats: MP3 and WAV.
  </ParamField>

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.neural4d.com/openapi/v1/files \
  --header 'Authorization: Bearer <token>' \
  --form 'file=@/path/to/file.png'
```

```python Python
import requests

    "https://api.neural4d.com/openapi/v1/files",
    headers={

    },
    files={"file": open('/path/to/file', 'rb')},
)
print(response.json())
```
