---
title: "Retrieve a task"
sidebarTitle: "Retrieve a task"
description: "Returns image, video, or 3D task status and output by batch task ID or child item UUID. Provide exactly one of the id or uuid query parameters."
api: "GET https://api.neural4d.com/openapi/v1/tasks/task-info"
playground: simple
authMethod: bearer
---

Depending on the task type, `output` contains a `models` (3D), `images`, or `videos` array. Queued and processing entries also include generation parameters.

## Authorizations

<ParamField header="Authorization" type="string" required default={'Bearer ${YOUR_API_KEY}'}>
  Neural4D API key using the Bearer scheme.
</ParamField>

## Query Parameters

<ParamField query="id" type="string">
  Batch task ID returned by a generation request. Provide this or uuid, but not both.

Example: `"normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d"`.
</ParamField>
<ParamField query="uuid" type="string&lt;uuid&gt;">
  Child image, video, or 3D UUID returned in the generation response. Provide this or id, but not both.

Example: `"72e30159-a242-4491-a67c-2ad0cfc9efb6"`.
</ParamField>

## 3D rendering resources

Examples with all resources available, excluding thumbnails. Actual file counts depend on which files have been generated.

| Model type | `model_urls` | `texture_urls` | Example file count |
| --- | --- | --- | --- |
| Triangle mesh, textured model, or PBR model | `glb` | Omitted; materials and textures load with the GLB | 1 |
| Untextured quad mesh | `obj` | Omitted | 1 |
| Quad model with ordinary textures | `obj`, `mtl` | `albedo` | 3 |
| Quad PBR model | `obj`, `mtl` | `albedo`, `normal`, `roughness`, `metallic` | 6 |

Texture filenames must match the references in the MTL.
