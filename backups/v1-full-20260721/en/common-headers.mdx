---

## Authentication

Send the API key with the Bearer scheme on every request.

```http
Authorization: Bearer ${YOUR_API_KEY}
```

## Request tracing

`X-Request-Id` is optional. Supply a unique value when you need to correlate your logs with Neural4D support or server logs. If omitted, the service generates one. The effective value is returned in the response.

```http
X-Request-Id: req_01J2R6Y7F6Q8K9P0M1N2B3V4CX
```

| Header | Direction | Description |
| --- | --- | --- |
| `Authorization` | Request | Required API key using the Bearer scheme. |
| `X-Request-Id` | Request and response | Optional client trace ID; generated by the service when omitted. |
| `x-ratelimit-limit-requests` | Response | Request limit for the active window. |
| `x-ratelimit-remaining-requests` | Response | Requests remaining in the active window. |
| `x-ratelimit-reset-requests` | Response | Time until the active window resets, such as `1s`. |
| `Retry-After` | 429 response | Seconds to wait before retrying. |
