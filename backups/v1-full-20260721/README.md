# Full v1 documentation backup

Created on 2026-07-21 before limiting the public v1 documentation to video generation and task retrieval.

This directory contains the complete English and Chinese v1 OpenAPI specifications, Mintlify navigation, quickstart and common-header pages, and the generator and validator used to produce that snapshot.

The active generator reads `openapi.json` from this directory as its full source contract, then publishes only the currently exposed public subset.
