This site documents the available Neural4D management APIs. Browse the API reference to view endpoint paths, parameters, response fields, and request examples.

<Note>
All endpoints use `Bearer token` authentication and the `https://alb.neural4d.com:3000` base URL. Most generation endpoints return a `uuid` or `uuids` first, which you then use to query the final result.
</Note>

## Included capabilities

- Text-to-3D model generation
- Image-to-3D model generation and chibi-style model generation
- Picture generation and video generation
- Generation result lookup and job progress lookup
- Model format conversion and download
- Portrait image detection and points balance queries
