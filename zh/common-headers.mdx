## Authorization

每个请求都需要使用 Bearer 方式发送 API 密钥。

```http
Authorization: Bearer ${YOUR_API_KEY}
```

## X-Request-Id

`X-Request-Id` 为可选请求头，用于关联客户端日志和 Neural4D 日志。未提供时，服务会生成该值并在响应中返回。

```http
X-Request-Id: req_01J2R6Y7F6Q8K9P0M1N2B3V4CX
```

| 请求头 | 方向 | 说明 |
| --- | --- | --- |
| `Authorization` | 请求 | 必填，使用 Bearer 方式发送 API 密钥。 |
| `X-Request-Id` | 请求和响应 | 可选的请求追踪 ID；未提供时由服务生成。 |
