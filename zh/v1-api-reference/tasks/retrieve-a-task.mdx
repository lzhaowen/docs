sidebarTitle: "查询任务"
description: "按批次任务 ID 或生成结果子项 UUID 返回图片、视频、3D 任务状态和输出。id 与 uuid 必须且只能传入一个。"
api: "GET https://api.neural4d.com/openapi/v1/tasks/task-info"
playground: simple
authMethod: bearer
---

根据任务类型，`output` 仅包含 `models`（3D）、`images`（图片）或 `videos`（视频）中的一个数组。排队和处理中的条目也会返回生成参数；结果文件可用前，`url` 和 `format` 为 `null`。

## 授权

<ParamField header="Authorization" type="string" required default={'Bearer ${YOUR_API_KEY}'}>
  使用 Bearer 方式发送的 Neural4D API 密钥。
</ParamField>

## 查询参数

<ParamField query="id" type="string">
  生成请求返回的批次任务 ID。与 uuid 二选一，不能同时传入。

示例：`"normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d"`。
</ParamField>
<ParamField query="uuid" type="string&lt;uuid&gt;">
  生成响应返回的图片、视频或 3D 子项 UUID。与 id 二选一，不能同时传入。

示例：`"72e30159-a242-4491-a67c-2ad0cfc9efb6"`。
</ParamField>
