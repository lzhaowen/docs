使用 `https://api.neural4d.com/openapi/v1` 作为基础路径，并通过 `Authorization: Bearer ${YOUR_API_KEY}` 发送 API 密钥。

<Note>
  视频生成请求使用 JSON。首帧和尾帧图片放在 `frame_images` 中，带类型的图片、视频或音频参考素材放在 `input_references` 中。所有输入素材都需要先上传，并使用返回的 `file_id`。
</Note>

## 调用流程

1. 通过 `POST /openapi/v1/files` 上传每个可复用素材，并保存返回的 `file_id`。
2. 提交 `POST /openapi/v1/videos/generations` 并保存返回的批次任务 `id`。
3. 轮询 `GET /openapi/v1/tasks/task-info?id={id}`，直到任务进入终态。
4. 从 `output.videos` 读取子项 `uuid`、`aspect_ratio`、`mode` 和生成的视频 URL。
