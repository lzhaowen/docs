本文档整理了 Neural4D 管理接口。你可以在 API 参考中查看接口路径、请求参数、返回字段和请求示例。

<Note>
  从左侧导航打开中文 API 参考，也可以切换到英文查看英文 API 参考。接口路径、参数名、枚举值和真实响应字段仍保持英文原样。
</Note>

## 当前包含的能力

- 文本生成 3D 模型
- 图片生成 3D 模型和 Q 版模型
- 图片生成和视频生成
- 查询生成结果和任务进度
- 转换模型格式并下载结果
- 检测人像图片和查询剩余点数
