API v1 基础地址为 `https://api.neural4d.com/openapi/v1`。以下通过文生 3D 演示核心调用流程。

## 1. 配置 API 密钥

使用有效付费订阅账户，在 [API Key 页面](https://www.neural4d.com/account?api) 获取密钥。

## 2. 创建 3D 生成任务

提交提示词，生成带纹理的 3D 模型。每次请求都通过 `Authorization: Bearer` 携带密钥。

```bash cURL
curl --request POST \
  --url 'https://api.neural4d.com/openapi/v1/3dmodels/generations' \
  --header "Authorization: Bearer ${YOUR_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "dreamtech/neural4d-2.5",
    "prompt": "白色摄影棚背景中的陶瓷茶壶",
    "with_texture": true
  }'
```

接口返回 `202 Accepted`。保存任务 `id`，用于后续查询。

```json 202 Accepted
{
  "id": "normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d",
  "status": "queued",
  "created_at": 1784044800,
  "mode": "text_to_3d",
  "model": "dreamtech/neural4d-2.5",
  "data": [
    {
      "uuid": "72e30159-a242-4491-a67c-2ad0cfc9efb6",
      "status": "queued",
      "created_at": 1784044800
    }
  ],
  "usage": {
    "credits": 30
  }
}
```

## 3. 查询并下载结果

将下面的 `id` 替换为创建任务返回的值，间隔数秒查询一次。`queued` 和 `processing` 表示尚未完成；`succeeded` 表示成功，`failed` 表示失败，此时查看响应中的 `error`。

```bash cURL
curl --request GET \
  --url 'https://api.neural4d.com/openapi/v1/tasks/task-info?id=normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d' \
  --header "Authorization: Bearer ${YOUR_API_KEY}"
```

```json 200 OK
{
  "id": "normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d",
  "status": "succeeded",
  "model": "dreamtech/neural4d-2.5",
  "created_at": 1784044800,
  "updated_at": 1784044842,
  "mode": "text_to_3d",
  "output": {
    "models": [
      {
        "uuid": "72e30159-a242-4491-a67c-2ad0cfc9efb6",
        "url": "https://cdn.neural4d.com/results/model.glb",
        "format": "glb",
        "thumbnail_url": "https://cdn.neural4d.com/results/t1.png",
        "mesh_quality": "standard",
        "pose": "auto",
        "target_polycount": 500000,
        "topology": "triangle",
        "with_texture": true,
        "with_pbr": false,
        "image_enhancement": false,
        "mode": "text_to_3d",
        "status": "succeeded",
        "created_at": 1784044800,
        "updated_at": 1784044842
      }
    ]
  },
  "usage": {
    "credits": 30
  }
}
```

成功后，使用 `output.models[0].url` 下载模型文件，使用 `output.models[0].thumbnail_url` 查看模型预览图。两个地址均为临时签名 URL，过期后可重新查询任务获取。
