API v1 基础地址为 `https://api.neural4d.com/openapi/v1`。以下通过文生 3D 演示核心调用流程。各语言示例均从环境变量 `YOUR_API_KEY` 读取密钥。

## 1. 配置 API 密钥

使用有效付费订阅账户，在 [API Key 页面](https://www.neural4d.com/account?api) 获取密钥。

```bash 配置 API 密钥
export YOUR_API_KEY='替换为你的 API 密钥'
```

## 2. 创建 3D 生成任务

提交提示词，生成带 PBR 材质的 3D 模型。需要同时设置 `with_texture: true` 和 `with_pbr: true`。每次请求都通过 `Authorization: Bearer` 携带密钥。

<div data-api-example="request">
<CodeGroup>
```bash cURL · 创建 PBR 模型
curl --request POST \
  --url "https://api.neural4d.com/openapi/v1/3dmodels/generations" \
  --header "Authorization: Bearer ${YOUR_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "dreamtech/neural4d-2.5",
  "prompt": "白色摄影棚背景中的陶瓷茶壶",
  "with_texture": true,
  "with_pbr": true
}'
```

```java Java · 创建 PBR 模型
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

class Main {
  public static void main(String[] args) throws Exception {
    String apiKey = System.getenv("YOUR_API_KEY");
    String payload = String.join("\n",
        "{",
        "  \"model\": \"dreamtech/neural4d-2.5\",",
        "  \"prompt\": \"白色摄影棚背景中的陶瓷茶壶\",",
        "  \"with_texture\": true,",
        "  \"with_pbr\": true",
        "}"
    );

    HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("https://api.neural4d.com/openapi/v1/3dmodels/generations"))
        .header("Authorization", "Bearer " + apiKey)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString(payload))
        .build();
    HttpResponse<String> response = HttpClient.newHttpClient().send(
        request,
        HttpResponse.BodyHandlers.ofString()
    );
    System.out.println(response.body());
  }
}
```

```go Go · 创建 PBR 模型
package main

import (
    "fmt"
    "io"
    "log"
    "net/http"
    "os"
    "strings"
)

func main() {
    apiKey := os.Getenv("YOUR_API_KEY")
    payload := strings.NewReader(`{
      "model": "dreamtech/neural4d-2.5",
      "prompt": "白色摄影棚背景中的陶瓷茶壶",
      "with_texture": true,
      "with_pbr": true
    }`)
    request, err := http.NewRequest(
        "POST",
        "https://api.neural4d.com/openapi/v1/3dmodels/generations",
        payload,
    )
    if err != nil {
        log.Fatal(err)
    }
    request.Header.Set("Authorization", "Bearer "+apiKey)
    request.Header.Set("Content-Type", "application/json")

    response, err := http.DefaultClient.Do(request)
    if err != nil {
        log.Fatal(err)
    }
    defer response.Body.Close()
    body, err := io.ReadAll(response.Body)
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(string(body))
}
```

## 3. 查询并下载结果

将下面的 `id` 替换为创建任务返回的值，间隔数秒查询一次。`queued` 和 `processing` 表示尚未完成；`succeeded` 表示成功，`failed` 表示失败，此时查看响应中的 `error`。

<div data-api-example="request">
<CodeGroup>
```bash cURL · 查询任务

  --url "https://api.neural4d.com/openapi/v1/tasks/task-info?id=normal-3d-c50fe63e-699d-4d61-93f5-2099ab159d6d" \
  --header "Authorization: Bearer ${YOUR_API_KEY}"
```
