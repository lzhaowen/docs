## 授权

<ParamField header="Authorization" type="string" required default={'Bearer ${YOUR_API_KEY}'}>
  使用 Neural4D 网站提供的 Bearer token。
</ParamField>

## 请求体 <span className="api-content-type">multipart/form-data</span>

<ParamField body="images" type="string&lt;binary&gt;[]" required>
  用于生成 Q 版模型的输入图片文件。

数组长度：至少 `1` 个元素。
</ParamField>
<ParamField body="styleType" type="string" required>
  Q 版模型流程使用的已配置提示词标签。

示例：`"Pixel-Style"`。
</ParamField>

<RequestExample>
```bash cURL
curl --request POST \
  --url https://alb.neural4d.com:3000/api/createCuteModelsFromImages \
  --header 'Authorization: Bearer <token>' \
  --form 'images=@/path/to/file' \
  --form 'styleType=Pixel-Style'
```
