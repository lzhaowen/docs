## 授权

<ParamField header="Authorization" type="string" required default={'Bearer ${YOUR_API_KEY}'}>
  使用 Neural4D 网站提供的 Bearer token。
</ParamField>

## 请求体 <span className="api-content-type">multipart/form-data</span>

<ParamField body="image" type="string&lt;binary&gt;" required>
  用于检测的人像图片。支持 JPG、JPEG 和 PNG。
  </ParamField>

<RequestExample>


## 响应

<Tabs sync={false}>
  <Tab title="200">
    检测结果
        
    <ResponseField name="statusCode" type="enum&lt;integer&gt;" required>
      检测状态。`0` 表示结果有效，`-1` 表示结果无效。

    可选值：`-1`、`0`。
    </ResponseField>



    <ResponseField name="result" type="boolean" required>
      上传图片中是否检测到人像。
    </ResponseField>



    <ResponseField name="message" type="string" required>
      可读的人像检测结果说明。
    </ResponseField>
  </Tab>
</Tabs>

<ResponseExample>
```json 200 portraitDetected
{
  "statusCode": 0,
  "result": true,
  "message": "success"
}
```

```json 200 rateLimited
{
  "statusCode": -1,

```
